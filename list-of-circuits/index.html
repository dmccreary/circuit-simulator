    List of Circuits¶

    This page lists every example circuit in the Circuits menu of Paul Falstad's circuit simulator. There are 366 entries (365 unique circuit files) in 56 categories.

    Sources¶

    The list has two sources:

    • Current list. The categories, names, and order come from src/com/lushprojects/circuitjs1/public/setuplist.txt in pfalstad/circuitjs1, Paul Falstad's repository for the browser version of the simulator, at commit 5a70716 (setuplist.txt last changed on 2026-07-07). Each entry links to its circuit file there, which can be opened in the simulator.
    • 2013 list. The first version of this page was built from src/setuplist.txt in hausen/circuit-simulator, a fork of the older Java simulator whose circuit list dates from 2013-05-08. The current list was compared against it, file by file.

    Since 2013, 87 circuits and 12 categories have been added, and none have been removed. A circuit that was not in the 2013 list is marked New since the 2013 list. A circuit that has moved to another category or been renamed says so in its entry.

    Where the menu nests a submenu inside a category, the heading shows every level, such as Op-Amps: Amplifiers. The circuit names are the menu labels, so a short name like I/V Curve is read together with its category heading. The menu's Blank Circuit item is an empty starting point, not a circuit, so it is not listed. The repository also holds a few example files that are not in the menu, such as the AVR8js microcontroller demos, and these are not listed either.
